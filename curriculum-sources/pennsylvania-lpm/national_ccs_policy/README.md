# national_ccs_policy

Federal/multi-state actors in the Kitzmiller v. Dover case: NCSE, Discovery
Institute, Americans United for Separation of Church and State, the ACLU,
Thomas More Law Center, and Pepper Hamilton LLP. See
`state/pennsylvania/local_policy/` for the Pennsylvania-specific actors
(PDE, the State Board, IRRC, Dover Area School District).

## What's here

[`records/institutional-actors.yaml`](records/institutional-actors.yaml) — 6
actor records. Several (NCSE, Discovery Institute) overlap in real-world
identity with actors already modeled independently in `florida-lpm`'s own
`national_ccs_policy/` — modeled here with this repo's own id prefix, per
this ecosystem's current informal (not cross-repo-validated) reference
convention.
