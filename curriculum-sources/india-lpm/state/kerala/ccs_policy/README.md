# state/kerala/ccs_policy

OpenEvo-authored CCS/interdisciplinary policy-principle records for
Kerala, founded 2026-10-09 alongside a first real research pass into
forest-dwelling Scheduled Tribe communities whose children board away
from family at residential schools, grounded in
[`../local_policy/`](../local_policy/)'s institutional actors, timeline
events, and coherence findings. Written toward the broader question this
pass was asked to think about: what a model Learning Progression Map for
Kerala's diverse communities would need to look like to stay compliant
with the state curriculum (KCF) while genuinely navigating the space
between local/indigenous and state/global knowledge, with real
student agency and teacher-student co-agency.

These carry the ordinary `review_status` lifecycle (draft → proposed →
adopted). They do not carry `verificationStatus` -- see
[`../../../GOVERNANCE.md`](../../../GOVERNANCE.md). A principle's
real-world credibility is only as strong as the `local_policy` records
it's `groundedIn`, most of which are `unverified-secondary-source` today
-- see each record's own `provenance.contributor_notes` for exactly what
was and wasn't directly verified.

**None of this has been reviewed by anyone with direct knowledge of these
communities.** [`INLP-PRINCIPLE-consultation-before-content-not-extraction`](records/policy-principles.yaml)
exists specifically to say so and to name what has to happen before that
changes.
