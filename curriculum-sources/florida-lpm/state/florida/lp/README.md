# state/florida/lp

Metadata ABOUT how far a crosswalk between Florida's official standards and
this ecosystem's own machine-readable curriculum-graph data has progressed —
not a document archive and not a re-implementation of FLDOE's standards
themselves. See `../../../case/README.md` for the actual CASE-format files
these crosswalk records point at.

## Contents

[`records/crosswalk.yaml`](records/crosswalk.yaml) — 3 crosswalk records:
one documenting the **Common Standards Project API**
(`api.commonstandardsproject.com`), confirmed live and fetched directly this
founding session via plain REST calls — the complete, real, CC-BY-3.0-US-licensed
text of Florida's SC.912.L.15 evolution standard, not a secondary mirror;
one pointing at this repo's own CASE-format file for SC.912.L.15
(`sourceSystem: openevo-graph-case-format-local-file`), transformed from that
confirmed source into `openevo-graph/schema/case_schema.json`'s shape; and
one pointing at `bio-core-k12`'s existing, concept-tagged
natural-selection/adaptation LPM strand (`sourceSystem:
openevo-conceptbase-competencybase-informal-refs`) — flagging that this
ecosystem already has mature curriculum content for exactly what Florida's
2026 draft is reportedly sidelining.
